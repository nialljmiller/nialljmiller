# 👤 Niall Miller

**Astrophysicist · Scientific software developer · ML/HPC for stellar astronomy**

I build research software for stellar evolution, synthetic photometry, Galactic archaeology, and large-scale astronomical time-series analysis. My work sits at the messy but useful intersection of **MESA**, **survey astronomy**, **machine learning**, **Fortran/Python**, and **high-performance computing**.

[🌐 Website](https://nialljmiller.com) · [🐙 GitHub](https://github.com/nialljmiller) · [🧪 ORCID](https://orcid.org/0000-0002-3780-0592)

## 🔧 Main things I build

### 🌈 MESA / synthetic photometry
- Developer of **MESA Custom Colors**, bringing synthetic photometry directly into stellar evolution workflows.
- Author of **SED_Tools**, a Python toolkit for atmosphere grids, filter curves, and synthetic photometry pipelines.
- Bridging stellar theory and observables: `Teff`, `log g`, `[M/H]`, SEDs, magnitudes, and survey filters.

### 🤖 Machine learning for astronomical surveys
- Creator of **NN_FAP**, a neural-network false-alarm framework for variable-star period detection.
- Developer of PRIMVS-related ML tools for large-scale infrared variable-star classification.
- Experience with XGBoost, contrastive learning, recurrent networks, embeddings, and survey-scale catalog work.

### 🧬 Galactic archaeology / chemical evolution
- Developer of GA/SMC-DEMC optimization tools for Galactic Chemical Evolution models.
- Fits high-dimensional, mixed discrete/continuous astrophysical models using HPC-scale search methods.

### 🖥️ Scientific computing
- Python · Fortran · PyTorch · Astropy · MESA · SLURM · Linux · HPC workflows
- Open-source tools, reproducible pipelines, data products, and teaching material.
